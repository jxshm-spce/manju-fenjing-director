# 漫剧分镜提示词导演

将 AI 漫剧剧本或分镜转成中文时间轴视频提示词。

## 主要功能

- 按“时间、时段环境、景别、镜头类型、人物站位与镜头、画面描述、节奏锚点、台词”组织输出。
- 生成前确认使用 2.0 还是 2.5；按本工作流规则，每段分别不超过 15 秒或 30 秒。
- 段尾优先交代人物站位的大远景或便于衔接的特写，默认避开双人中景。
- 保留人物站位、表演、光学、物理、灯光、声音和道具连续性。

## 使用

在支持本技能格式的工具中导入 [1.0.0 技能包](dist/manju-fenjing-director-1.0.0.zip)，或使用仓库内的 SKILL.md、agents 与 references 文件。

调用示例：

> 使用“漫剧分镜提示词导演”，将下面的剧本转成时间轴提示词；先确认视频版本，再安排片段。

机器标识：`manju-fenjing-director`。技能包版本：`1.0.0`。

本技能提供提示词指导，不包含视频生成接口或账号凭证。15／30 秒为本技能的制作分段规则，平台实际能力以所用入口为准。
