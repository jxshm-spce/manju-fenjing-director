# 《旧信》：从短剧本到两段提示词

[← 返回项目首页](../README.md) · [使用指南](usage.md)

这是为说明格式而写的原创文本演示，不是实际生成视频的效果证明。视频版本已明确选择 **2.0**，因此直接展示分段结果；未选择时应先询问版本。

## 输入：剧本与制作要求

> 夜，旧书店。西侧是门，东侧是窗，书桌横放在两人之间。林夏站在书桌西端，陈舟站在书桌东端，相距约两米。摄影机从书桌南侧拍摄，林夏在画面左边，陈舟在右边。窗外冷光与桌灯暖光混合。保持用户指定画风。
>
> 林夏右手拿着一只未封口的信封，看向陈舟：“你还是来了。”
>
> 陈舟看着她：“我来拿回那封信。”
>
> 林夏低头，把信封沿桌面推到陈舟一侧的桌沿。陈舟先用左手按住信封，林夏松手。陈舟没有拿起信，抬眼看向林夏。两人停在桌子两端。

制作要求：用 2.0，规划为两个 12 秒片段；保留两句原台词；没有其他人声、字幕或音乐。演示不使用虚构的参考标签。角色外观以制作时提供的参考为准。

## 这两个片段怎样接起来

| 连续信息 | 片段一结束 | 片段二开始 |
| :--- | :--- | :--- |
| 摄影机 | 在书桌南侧俯拍 | 仍从南侧俯拍 |
| 信封 | 停在东端桌沿，封口朝北 | 同一位置、同一朝向，尚未被拿起 |
| 林夏的右手 | 指尖停在信封左边缘 | 先保持接触，待陈舟按住后才收回 |
| 陈舟的左手 | 尚未伸入特写 | 从画面右侧伸入，按住信封右边缘 |
| 光线 | 东窗冷光与桌灯暖光 | 方向与亮度保持一致 |

片段一用特写提供明确切点；片段二从静止状态继续交接动作，最后用大远景交代两人的站位。每段都从 `00:00` 重新计时，总时长分别为 12 秒。

如果本项目选用 **2.5**，这个 24 秒场景也可以规划为一个片段，在自然节奏下重新安排时间码；30 秒只是上限，无需额外扩写到 30 秒。具体动作和台词仍以原剧本为准。
