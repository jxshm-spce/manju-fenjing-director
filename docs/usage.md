# 使用指南

[← 返回项目首页](../README.md)

## 最快的两种用法

### 下载安装包交给智能体

1. [下载 manju-fenjing-director-1.0.0.zip](https://github.com/jxshm-spce/manju-fenjing-director/raw/refs/heads/main/dist/manju-fenjing-director-1.0.0.zip)。这是专用技能包，包含核心规则、界面元数据和交付模板。
2. 把 ZIP 作为附件拖进智能体，或在其技能管理入口导入。
3. 让智能体读取 `SKILL.md` 与 `references/output-format.md`，按当前平台支持的方式安装或载入。

可直接复制：

```text
请安装并使用附件中的“漫剧分镜提示词导演”Skill。
请读取 SKILL.md 与 references/output-format.md。
如果当前平台只支持在本次对话中读取使用，请明确说明。
接下来我会提供剧本。
```

### 把 GitHub 地址发给智能体

适用于能够读取 GitHub 仓库内容的智能体：

```text
请读取并使用这个项目中的“漫剧分镜提示词导演”：
https://github.com/jxshm-spce/manju-fenjing-director

读取根目录 SKILL.md 和 references/output-format.md，
按当前平台的技能机制安装或载入。
```

如果智能体只能看到网页简介，让它继续打开这两个文件。若它无法访问 GitHub，就使用 ZIP 或把解压后的文件作为附件提供。只读取说明与长期安装是两种状态，可以让智能体说明当前采用哪一种。

## 手动放置文件

下载并解压专用 ZIP 后，保留以下目录关系：

```text
manju-fenjing-director/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    └── output-format.md
```

把整个 `manju-fenjing-director` 文件夹放到目标工具的技能目录，或按它的导入说明选择这一层目录。不要只复制 `SKILL.md`，否则会缺少时间轴模板。刷新技能列表或重新打开会话后，检查是否出现“漫剧分镜提示词导演”；具体加载方式以目标工具为准。

机器标识为 `manju-fenjing-director`，中文展示名为“漫剧分镜提示词导演”。支持 `$技能名` 语法的工具中，可以使用 `$manju-fenjing-director`；其他工具中直接说中文技能名即可。

## 第一次交稿需要什么

**至少提供剧本或现有分镜。** 下面这些资料有就一起给，不需要为了启动而全部补齐：

| 资料 | 能帮助确定什么 |
| :--- | :--- |
| 本次使用 2.0／2.5 | 每段按 15 秒还是 30 秒上限规划 |
| 角色档案或人物设定 | 性格、行为习惯、固定声线和剧情阶段 |
| 角色／场景／道具参考图及原始标签 | 身份、外观和参考对应关系 |
| 已有片段的尾帧或状态描述 | 下一段首帧、持物手、方向和光线衔接 |
| 画风、画幅与特殊机位要求 | 本项目的视觉约束 |
| 集数、场次和片段编号 | 交付时保留已有标识 |

### 一次提交的范本

```text
使用“漫剧分镜提示词导演”。本项目用 2.5，每段不超过 30 秒。
将下面剧本转成中文时间轴提示词，保留原台词与剧情。
段尾尽量安排能衔接的远景或特写，避免双人中景。

画风：按我提供的参考图保持一致。
已有角色档案：见附件；没有写明的设定不要当成既定事实。
参考标签：按我提供的实际标签原样使用。
特殊要求：在这里写固定机位、一镜到底或其他要求。

剧本：
……
```

未指定视频版本时，技能会先询问 2.0 或 2.5，并在你回答后再规划片段。同一项目沿用选择；需要切换时直接说“后面改用 2.0，重新核对分段”。

## 后续修改怎么说

```text
修改片段二：林夏始终用右手接触信封，不要换手。
保留原台词和总时长，把尾镜改为能交代两人站位的大远景。
同时检查片段三的开头是否接得上。
```

明确指出片段、需要保留的内容与目标，比只说“更有电影感”更容易得到可用修改。参考素材更新后，把实际标签一并给出。

## 检查是否按规则工作

可以用一场短戏试用。未选择版本时，应先收到版本询问；明确选择后，应收到带时间码的中文提示词。

检查这些可见结果即可：

- 每个生成片段的实际时长在所选上限内，子镜头时间与总时长对应。
- 时间、时段环境、景别、镜头类型、人物站位与镜头、画面描述、节奏锚点和台词栏目齐全。
- 原台词保留，人物、持物手和道具状态能跨段接续。
- 片段最后一镜按剧情优先选择大远景或特写；有明确特殊要求时尊重该要求。

想先看完整交付，可阅读[《旧信》演示](example.md)。这个 Skill 的产物是提示词文本，视频画面仍由你使用的生成工具产生。
