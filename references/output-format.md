# 时间轴分镜提示词：固定交付格式

本格式根据用户提供的《分镜提示词 .docx》中带时间轴的主要案例整理，只提取栏目顺序与层级。原案例的具体人物、故事、台词、画风、光线、镜头数量、双人中景和时长都不是新任务的默认内容。该文件是自足模板，日后无需访问原 Word 或微信目录。

## 生成片段与时间段

- 一个“生成片段”是一次提交给视频模型的完整提示词，时长受本项目已选择版本的上限约束；一个片段可以包含多个“时间段”，每个时间段可以包含一个或多个子镜头。
- 完整剧本可拆成多个生成片段。标题使用用户已有集数、场次或片段标识；未给集数时只按片段编号，不编造集数。
- 默认每个生成片段的时间码从 `00:00` 开始，内部连续排列；下一生成片段重新从 `00:00` 开始。若用户明确指定全局时间码则保留，但以结束减开始计算每段实际时长，不能因时间码绝对值大于 15／30 就误判超时。
- 每段末尾的“时长”是该生成片段的实际规划时长，不是版本上限，也不是全剧总时长。分段后不以同一个“时长：30秒”覆盖多个片段。

## 固定模板

标题之后，每个时间段按以下栏目顺序输出。栏目各自换行；有下一个时间段就重复整组，不只交一串子镜头。

```text
分镜提示词
[用户已有标识／片段一]

时间：00:00-00:04
时段环境：[时段、天气或室内外、地点、影响画面的环境与光线]
景别：[按实际子镜头顺序，例如：过肩近景 → 手部特写]
镜头类型：[硬切／正反打／跟拍／推拉等真实衔接和运动方式]
人物站位与镜头：
【镜头一・[内容]】00:00-00:02：[机位、景别、主体的画面位置和深度、身体朝向、视线目标、道具接触、可见动作与反应。]
【镜头二・[内容]】00:02-00:04：[切换方式、机位与景别，以及承接前镜的状态。]
画面描述：[按镜头顺序补足动作因果、物理表现和连续关系，不重复整段站位说明。]
节奏锚点：[关键事件／动作／反应 → 后续变化]
台词：[说话者（子镜头、必要时点及说话方式）：原文台词；没有则写“无台词”。]

[后续时间段重复以上栏目，并按实际时长排列]

时长：[本生成片段的实际秒数]
```

模板里的 4 秒、两镜和占位符只示范格式，不是固定节奏。每组按实际需要采用一镜、两镜或多镜；同一时间段内子镜头依次为“镜头一、镜头二、镜头三……”，下一时间段可按参考案例重新从“镜头一”编号，由时间码区分。

所有子镜头准确覆盖所属时间段，不越界、重叠或留下未解释的空白。单一连续镜头也使用这些栏目，只写实际发生的一镜或连续运动，不虚构硬切。连续拍摄中仅分时间段时，要明确镜头持续、不切换。

默认保留以上全部栏目。原文无天气时不编天气，材料未确定时简洁标注，不增加不必要的确认问题；用户当次明确另定格式时按其要求。

## 把原导演控制写进这些栏目

| 原控制内容 | 写入位置 |
|---|---|
| 当前参考、人物身份锚点 | 相应子镜头的人物标识与描述，只用该段实际需要的原始 @标签 |
| 空间地图、首帧、视线、地标距离 | 人物站位与镜头；首个子镜头明确首帧状态 |
| 光学、距离、对焦、摄影机运动 | 镜头类型及具体子镜头，不再额外排一套光学栏目 |
| 灯光、曝光、材质、风雨 | 时段环境和实际子镜头；关键锁定放在相关动作旁 |
| 动作节拍、重量、接触与延迟 | 子镜头、画面描述和节奏锚点 |
| 台词、嘴部状态、说话时点 | 台词栏和对应子镜头 |
| 固定声线、环境声、音效、音乐限制 | 有实际需要时在该组台词之后增加“声音：”；固定声线原文复用 |
| 段尾衔接与下一段首帧 | 本段最后一个子镜头及下一段第一个子镜头各自写清具体状态 |

“声音”是参考案例中出现过的可选栏，仅在需要控制时加入，不替换其他栏目。无台词时仍保留“台词：无台词”；没有说话者就不补固定声线。

不要默认另附“场景概述／当前参考／场景空间地图／光学／摄影机／动作时间轴／物理表现／灯光／正向约束”等独立大纲。需要的控制内容应融入上表位置，避免把新格式和旧格式重复交付两遍。

## 段尾与下一段首帧

最后一个子镜头优先是：

- **交代空间的大远景：**人物必须实际出现在可定位的环境中，明确相互位置、地标、朝向和距离，不用没人或看不清人物位置的空风景代替。
- **可匹配的特写：**明确谁的脸、哪只手或哪件道具，保留视线方向、持物手、接触与动作完成状态，给下一段相同对象或反应提供具体切点。

下一段开头直接描述承接后的现实状态，不只写“接上一段”。不必逐帧复制上一段尾帧，但人物位置、动作方向、手部与道具状态、光线以及剧情时间必须能对上。下一段尚未提供时保留稳定、可读的尾帧，不编造下一段剧情。

只对整个生成片段的最后一镜落实段尾偏好，不要求每个时间段都以远景或特写结束。收尾必须计入本段上限，有合理观看时间；不要为了补一个远景或特写而超时，也不要停在无法辨认的半帧或无因跳切。
